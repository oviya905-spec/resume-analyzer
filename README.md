# 📄 Resume Analyzer - AI Powered Resume Builder

An AI-powered web application that helps students and job seekers create, analyze, and improve their resumes for better job opportunities.

### 🔗 Live Demo: (Coming Soon)
### 📂 GitHub: https://github.com/oviya905-spec/resume-analyzer

### ✨ Key Features
- 📝 **Resume Builder** – Create professional resumes using different templates
- 🤖 **ATS Resume Analysis** – Check whether the resume is ATS-friendly
- 📊 **Resume Score** – Provides a score based on resume quality and job requirements
- 🔍 **Keyword Analysis** – Identifies missing job-related keywords
- 💼 **Job Recommendations** – Suggests suitable job roles based on skills
- 🎓 **Course Recommendations** – Recommends relevant free courses to improve missing skills
- 🧠 **AI Skill Q&A** – Helps users understand technical skills and interview questions
- 👤 **User Login** – Personalized dashboard for managing resumes
- 📥 **Resume Download** – Download improved resume as PDF

### 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript / React
- Backend: Python / Node.js
- AI: NLP for ATS Scoring & Keyword Extraction
- Database: Firebase / MongoDB

### 🎯 Why this Project?
Many students' resumes get rejected by ATS systems. This project solves that by analyzing and improving resumes automatically.
